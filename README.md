# Health Tracker

A single-file, offline health tracker web app. All data stays in your browser (localStorage); nothing is sent anywhere.

Live: https://gretamolo.github.io/health-tracker/

Use Settings > Export data to back up, and Import data from backup to restore.

## Share with friends

A name-free copy is at **https://gretamolo.github.io/health-tracker/share/**. It has a generic greeting and asks the visitor's name on first open. It offers *Start blank* or *Load a starter setup* (morning vitamins, teeth, skin and an evening check-in, plus 2 weekly routines). It uses its own storage keys (`healthShare.*`), so it never mixes with the main app's data. Exercise pictures come from `../img/ex/`.
